# Информационные запросы по данным для дипломного проекта

Два запроса. Первый закрывает ёмкость объектов, второй — население по районам.
Оба подаются как **информационный запрос по Закону РК «О доступе к информации»
от 16 ноября 2015 года № 401-V**, срок ответа 15 календарных дней.

Канал подачи: [eotinish.kz](https://eotinish.kz/ru) (нужна ЭЦП НУЦ РК) либо через
[egov.kz, электронные обращения](https://egov.kz/cms/ru/services/e_app).

Важно: в поле темы или в первой строке прямо написать «информационный запрос
в соответствии с Законом Республики Казахстан "О доступе к информации"».
Без этой формулировки обращение уйдёт по общему треку рассмотрения обращений,
где другие сроки и другая логика ответа.

## Запрос 1. Управление образования города Астаны

**Адресат:** ГУ «Управление образования города Астаны»
**Адрес:** 010000, г. Астана, ул. Бейбитшилик, 11
**Телефоны:** +7 (7172) 55 68 51, 55 68 56, 55 74 23

### Текст

Информационный запрос в соответствии с Законом Республики Казахстан
«О доступе к информации» от 16 ноября 2015 года № 401-V.

Я, Болатов Диас, обучающийся Astana IT University по образовательной программе
6B06103 «Big Data Analysis», выполняю дипломный проект по теме оценки
пространственной доступности объектов социальной инфраструктуры города Астаны.
Работа носит некоммерческий академический характер.

Прошу предоставить следующую информацию.

**1. По государственным общеобразовательным школам города Астаны**, в разрезе
каждой организации:

- полное наименование организации;
- фактический адрес места нахождения;
- район города;
- проектная мощность в ученических местах;
- фактический контингент обучающихся на начало текущего учебного года;
- количество смен обучения;
- год ввода здания в эксплуатацию.

**2. По государственным дошкольным организациям города Астаны** (детские сады,
мини-центры), в разрезе каждой организации:

- полное наименование организации;
- фактический адрес места нахождения;
- район города;
- проектная мощность в местах;
- фактическая численность воспитанников;
- численность детей, состоящих в очереди на зачисление, в разрезе районов города.

**3. По объектам, введённым в эксплуатацию в рамках национального проекта
«Комфортная школа» в городе Астане в период с 2022 года по настоящее время**:

- наименование объекта;
- адрес;
- район города;
- проектная мощность в ученических местах;
- дата ввода в эксплуатацию.

Прошу предоставить информацию в электронном виде в формате электронной таблицы
(xlsx или csv). Если часть запрашиваемых сведений не входит в компетенцию
Управления, прошу направить соответствующую часть запроса надлежащему обладателю
информации в порядке, предусмотренном законом, и уведомить меня об этом.

**Адресат:** Бюро национальной статистики Агентства по стратегическому
планированию и реформам Республики Казахстан, департамент статистики

### Текст

Информационный запрос в соответствии с Законом Республики Казахстан
«О доступе к информации» от 16 ноября 2015 года № 401-V.

Я, Болатов Диас, обучающийся Astana IT University по образовательной программе
6B06103 «Big Data Analysis», выполняю дипломный проект по теме оценки
пространственной доступности объектов социальной инфраструктуры города Астаны.
Работа носит некоммерческий академический характер.

## Зачем каждый пункт

| Пункт | Что закрывает в работе |
|---|---|
| Проектная мощность школ и садиков | Слой предложения. Переводит анализ с покрытия на перегрузку, снимает главный риск проекта |
| Фактический контингент | Позволяет считать коэффициент загрузки, а не только формальную ёмкость |
| Количество смен | Прямой индикатор перегрузки. Трёхсменное обучение названо ключевой проблемой в приказе по нацпроекту |
| Очередь в дошкольные организации | Наблюдаемая мера неудовлетворённого спроса. Редкая и очень ценная переменная, годится как целевая для модели |
| Год ввода в эксплуатацию | Реконструкция состояния сети на 2021 год для бэктеста |
| Перечень «Комфортной школы» | Валидационная выборка: настоящие решения о размещении с датами и мощностями |
| Население по районам | Привязка дасиметрического перераспределения к официальным итогам |
| Возрастные группы по районам | Проверка реконструкции когорт из сеточных данных |
| Границы районов | Сопоставимость исторических данных после образования района Сарайшық |

## Если откажут

Отказ возможен только по информации ограниченного доступа. Запрашиваемые
показатели к таковым не относятся: проектная мощность и контингент публикуются
в отчётах акимата, очередь в дошкольные организации фигурирует в публичных
выступлениях. При отказе обладатель информации обязан указать основание.
В этом случае имеет смысл запросить те же данные в агрегированном виде
по районам города, что почти наверняка удовлетворят.

Работа остаётся защитимой и без ответа: слой ёмкости строится оценкой по
поэтажной площади зданий с калибровкой на объектах «Комфортной школы».
Ответ переводит эту часть из оценки в факт.
